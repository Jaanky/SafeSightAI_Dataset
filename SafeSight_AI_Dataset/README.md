# SafeSight AI: Smartphone Inertial Readings and Scene Images for Walking-Hazard Awareness

## Summary
120 static smartphone accelerometer and gyroscope readings across six location classes in and around a student hostel campus, plus a catalogue of 16 scene photographs. **14 rows are real field measurements; 106 rows are synthetic** (generated by `generate_synthetic.py` from statistics of the real rows). Every row is labelled in the `is_synthetic` column.

## Files
| File | Contents |
|---|---|
| sensor_readings_combined.csv | All 120 rows (14 real + 106 synthetic) |
| sensor_readings_real.csv | The 14 measured rows only |
| sensor_readings_synthetic.csv | The 106 synthetic rows only |
| class_summary.csv | Per-class counts and summary statistics |
| image_manifest.csv | Catalogue of 16 scene photographs (descriptions, hazard types, tags) |
| generate_synthetic.py | Seeded script that creates the synthetic rows (seed 20261105) |
| Dataset_Description_SafeSight_AI.pdf | Full dataset description |

## Data dictionary (sensor files)
| Column | Type | Description |
|---|---|---|
| record_id | text | SS-R01..SS-R14 real; SS-S001..SS-S106 synthetic |
| source | text | real or synthetic |
| is_synthetic | 0/1 | 0 = measured, 1 = generated |
| session | text | A or B (real field sessions); S (synthetic) |
| location_class | text | flat_ground, stairs, washing_area, balcony, outdoor_obstacle_area, door_threshold |
| hazard_type | text | Author annotation: none, level_change, wet_surface, open_edge, obstacle_uneven, threshold_step |
| location_name | text | Place name (real) or synthetic_<class> |
| acc_x_ms2, acc_y_ms2, acc_z_ms2 | number | Accelerometer axes, m/s2, gravity included |
| acc_magnitude_ms2 | number | sqrt(x^2 + y^2 + z^2) |
| tilt_pitch_deg | number | atan2(acc_z, acc_y) in degrees |
| gyro_x_rads, gyro_y_rads, gyro_z_rads | number | Gyroscope axes, rad/s |
| gyro_magnitude_rads | number | Vector magnitude of gyroscope axes |
| transcription_flag | text | Notes where handwriting was unclear (real rows) |

Image manifest columns: image_id, original_filename, scene_description, time_of_day, hazard_type, hazard_or_feature_tags, privacy_action_before_upload.

## How to use
1. Load `sensor_readings_combined.csv` (for example `pandas.read_csv`).
2. Filter with `is_synthetic == 0` to use measured data only.
3. Use `location_class` or `hazard_type` as the label for classification experiments.
4. Report the real/synthetic split in any results, and evaluate on real-only rows where possible.

## Known limitations
- Only 14 real rows; per-class synthetic statistics rest on 1 to 4 real readings.
- Readings are single static snapshots, not time series; class differences mostly reflect phone tilt.
- Real values were transcribed from handwritten notes; uncertain entries are flagged.
- Photographs are not linked to individual readings. Not validated for safety-critical use.
